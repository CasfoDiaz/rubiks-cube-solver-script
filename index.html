How it works

Three steps from scramble to solution

No setup wizard, no account, no learning curve.

1

Enter your scramble

Launch the app and paste the scramble your cube was mixed with. The parser validates the notation and flags any unrecognized move before solving.

2

Run the solver

Pick 3x3 or 2x2 and hit Solve. The script applies the layer-by-layer algorithm and validates the cube state at every stage.

3

Read the move sequence

Copy the grouped move list and follow it on your cube. Each phase is labeled so you always know which layer you're working on.

FAQ

Questions cubers ask

Quick answers about the Rubik's Cube solver script.

Is Solve The Cube Script really free?
Yes. The project is free and open source. You can download the Windows build from the release page, read the source code, and modify it for your own use under the project's license.
Which cube sizes are supported?
The solver currently supports the standard 3x3 Rubik's Cube and the 2x2 Pocket Cube. Both use standard Singmaster notation, so scrambles you find on WCA-style timers will work as-is.
